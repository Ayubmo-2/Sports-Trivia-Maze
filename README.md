# Sports Trivia Maze
A Java desktop game built as a group project — navigate through a maze by answering sports trivia questions, unlock doors to progress, and find your way to the exit before all paths are blocked.
> ⚠️ **No live link** — this is a Java desktop app. See [How to run](#how-to-run) below, or download the latest release (coming soon).
---
## Tech stack

* **Language** — Java
* **GUI** — Java Swing
* **Database** — SQLite
* **Build** — IntelliJ IDEA
---
## Features
* **Maze navigation** — move through a grid-based maze toward the exit
* **Trivia gates** — each door requires a correct sports trivia answer to unlock
* **Permanent locks** — wrong answers lock that door forever, forcing reroutes
* **Win/lose conditions** — escape the maze to win; get fully trapped and it's game over
* **Question bank** — sports trivia questions stored and queried from a local SQLite database
* **Save & load** — save your current game progress and resume later
